# 提灯者 · The Lantern Bearer

一款零依赖的 HTML5 Canvas 极简光影解谜游戏。全黑迷宫中，**鼠标就是提灯的光心**，一位速度只有 1.6px/帧的老年冒险家平稳地追着光走——比怪物慢，所以不能靠逃跑，只能靠光和地形。光照得到的地方才有路，墙会挡住光；怪物进光后要先刹车 0.18 秒才被冻住，期间碰到你依然会失败。找齐每关 3 枚碎片，走进右下角的大门。

---

## 1. 如何运行

**最简单：直接双击 `index.html`**，用 Chrome / Edge / Safari 打开即可。不需要 npm、不需要构建、不需要联网。

如果浏览器对本地文件有限制，也可以起一个本地服务器：

```bash
cd "interactive game"
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

调试用网址参数（写在文件路径后面）：

| 后缀 | 作用 |
| --- | --- |
| `#play` | 跳过标题页，直接从 Stage 1 开局 |
| `#stage2` / `#stage3` | 直接跳到对应关卡 |

页面**标题栏最右端、画布之外**有 `中 / EN` 切换按钮，点一下即可切换界面语言；选择会记住，下次打开保持。切换只改文字，不动游戏进度、计时、光心和怪物状态。

## 3. 坐标系与关卡数据写法

`levels.js` 里所有位置都用**网格坐标**，不是像素。运行时 `game.js` 会乘以 `level.cell` 换算成像素。

- 网格交叉点编号 `0 … cols`（横向）和 `0 … rows`（纵向）。
- 格子 `(c, r)` 的中心写作 `(c + 0.5, r + 0.5)`。
- 墙体 `[x1, y1, x2, y2]` 是一条水平或垂直线段，端点都在交叉点上。
  例如 `[1, 0, 6, 0]` 表示从 `(1,0)` 到 `(6,0)` 的墙。
- 入口固定在左上格 `(0,0)` 中心，出口固定在右下格 `(cols-1, rows-1)` 中心；外墙的左上、右下缺口就是入口和出口。

每关字段说明：

| 字段 | 含义 |
| --- | --- |
| `cols` / `rows` | 网格列数 / 行数 |
| `cell` | 每格像素数，`cols * cell = 600` |
| `lightRadius` | 光晕半径，也是怪物的冻结距离；光心跟随鼠标准星，不在角色身上 |
| `spawn` / `exit` | 起点 / 出口的网格坐标 |
| `fragments` | 3 枚碎片的坐标，碰到即拾取 |
| `monsters` | 怪物刷新点；带 `.5` 表示格子中心或通道中点 |
| `gates` | 光敏闸门：`switch` 是开关位置，`segment` 是被封住的通道线段 |
| `barriers` | 冻结影障：`axis` 移动方向，`fixed` 固定轴坐标，`from/to` 往返范围，`length` 自身长度，`speed` 速度 |
| `walls` | 全部墙体线段 |

手绘地图是规则网格（Stage 1 为 6×6，Stage 2 为 10×10，Stage 3 为 15×15），墙体坐标由图像逐像素提取后转成网格线段，因此与原图一致度很高。

### 碎片与机关的设计思路

- 碎片全部放在**死胡同**里，而不是主路径上，逼玩家绕路探索。
- Stage 1：1 只怪物 + 1 道光敏闸门，作为教学。
- Stage 2：2 只怪物 + 1 道光敏闸门。
- Stage 3：3 只怪物 + 1 道闸门 + 1 道影障，光半径缩到 85，走廊更窄。
- 光敏闸门只在**鼠标准星的光点**照到开关时打开，光移开后缓慢关闭；如果玩家正站在门里，门不会关上夹住玩家。开关判定只看距离，避免被闸门自身挡住而卡死。
- 影障与怪物共用"进光且视线通畅才冻结"规则。怪物额外有 **0.18 秒刹车**：先减速滑行，再定住；冻结时有白色描边圈，刹车时身后有两道红色划痕。
- **装饰特效**：老人会留下一串约 4.5 秒淡出的脚印，当前位置还有一个永远可见的小锚点（见 §4）；怪物离老人越近，红眼越亮、身体抖动越凶，但被光定住时不抖（见 §4）。

### 视线、阴影与光心

- **光心在鼠标准星**，不在角色身上。角色只是慢慢追光的本体；拾取、受伤、出口判定仍用本体脚点。
- 每帧会收集全部遮挡线段：静态墙、关闭的闸门、影障的四条边。
- **追逐**：怪物只有与玩家视线通畅、且距离不超过 `sightRange` 时才会追；否则进入巡逻。它的速度 2.2 比你快，所以别指望跑掉。
- **巡逻**：怪物没有地图，只在出生点 `patrolHome` 半径内沿通道乱走，撞墙就换方向。
- **冻结**：光心到怪物距离 ≤ `lightRadius` **且视线通畅**才会定住；隔着墙照不到，也不会冻。
- **刹车**：怪物刚进光不会瞬间停，而是进入 `braking`，按 `brakeTime` 线性减速滑行，结束后才变 `frozen`。光移开会取消刹车或解冻。刹车中、冻结中的怪物**都致命**——定住后仍要绕路，这就是"用光 + 地形反制"的核心。
- **光**：光晕不再是完美圆形——每帧从**光点**向每段遮挡物的两端投射阴影多边形，墙背后的区域会被重新涂黑。关闭的闸门和影障同样挡光。
- **亮度**：光晕内 70% 半径保持全亮，之后快速衰减；地面另有一层极淡的冷色光池，让光区范围与墙后阴影的边界更容易看清。`lightRadius` 不变。

## 4. 手感参数（在 `src/game.js` 顶部 `P` 对象）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `playerSpeed` | 1.6 | 本体最大速度，像素/帧（60fps 基准）；刻意慢于怪物 |
| `playerEase` | 0.05 | 追随插值比例，越小越"拖拽"；近处自动减速 |
| `stopDistance` | 2 | 光点离本体小于此距离时停步站立 |
| `walkFrameTime` | 0.16 | 行走两帧匀速切换周期（秒） |
| `playerRadius` | 5 | 脚点碰撞半径（拾取 / 受伤 / 出口都用它） |
| `playerDotRadius` | 2.2 | 脚下小白点半径 |
| `bodyHeadOffset` / `bodyHeadRadius` | 21 / 12 | 头肩代理圆（只用于撞墙，防止头埋进墙里） |
| `monsterSpeed` | 2.2 | 追逐速度，明显快于玩家 |
| `monsterRadius` | 12 | 怪物碰撞半径 |
| `brakeTime` | 0.18 | 怪物进光后的刹车时长（秒），结束后才冻结 |
| `patrolSpeed` | 1.15 | 怪物巡逻速度 |
| `patrolHome` | 130 | 巡逻活动半径（相对出生点） |
| `sightRange` | 300 | 怪物最大可视距离 |
| `wallThickness` | 7 | 墙体碰撞厚度（画出来是细线） |
| `pickupRadius` | 14 | 碎片拾取半径 |
| `footprintGap` | 14 | 每隔多少像素留一个脚印 |
| `footprintFade` | 4500 | 脚印淡出毫秒数（约 4.5 秒） |
| `footprintMax` | 48 | 最多同时保留的脚印数 |
| `eyeGlowRange` | 260 | 怪物红眼开始渐强的距离（像素） |
| `eyeGlowNear` | 60 | 小于此距离红眼强度封顶 |
| `shakeMax` | 2.6 | 怪物最大抖动幅度（像素，纯视觉） |
| `loseDelay` | 1500 | 失败后按 R 的冷却毫秒数 |
| `gateOpenRate` | 0.035 | 闸门每帧开启速度 |
| `gateCloseRate` | 0.018 | 闸门每帧关闭速度 |
| `gateOpenThreshold` | 0.55 | 开度超过此值才不阻挡 |

所有速度都按 `deltaTime` 归一化，高刷屏上不会变快。

### 平稳追光与怪物刹车

- **玩家**：本体连续、平稳地追随鼠标准星，限速 1.6px/帧，不再有支点、顿挫或左右交替侧晃。静止用 `standing`，移动时两张行走帧每 0.16 秒匀速交替，只有极轻微的上下颠簸。
- **为什么比怪物慢**：怪物 2.2px/帧，逃跑无效。生存靠两件事——用光点扫过去让它刹车冻结，以及利用墙体切断它的视线让它进入无地图巡逻。
- **刹车**：怪物进入光区后先滑行 `brakeTime`（0.18 秒），速度线性降到 0，之后才标记 `frozen`。刹车时身后画两道红色划痕，冻结时加白色描边圈。光移开会中断刹车或解冻。
- **危险**：刹车和冻结中的怪物依然会杀死你。定住它不等于可以穿过去，必须绕路——这就是地形反制的可玩性所在。

想调难度：改 `playerSpeed`（玩家快慢）、`brakeTime`（刹车长短，越短越容易突脸）、`monsterSpeed` / `patrolSpeed`（怪物压力）。

### 脚印轨迹与定位锚点

鼠标一甩远，老人还在黑暗里慢慢追——为了随时找得到他，加了两层永远可见的标记（都画在遮罩之后，不受黑暗影响）：

- **脚印**：本体每走 `footprintGap`（14px）留下一个淡色椭圆脚印，按时间线性淡出，`footprintFade`（4500ms）后消失；最多保留 `footprintMax`（48）个。只记录本体位置，不记鼠标光心。切关 / 重试会清空。
- **常亮锚点**：在本体当前位置画一个固定小圆圈 + 亮点。即使老人站着不动、脚印全淡光了，也能一眼看到他在哪。
- 这两层是纯装饰，**不影响任何判定**；拾取、受伤、出口仍用本体脚点。

### 怪物红眼与抖动

两都以**怪物到老人本体的实时距离**触发（不是到光心），进入 `eyeGlowRange`（260px）开始渐强，到 `eyeGlowNear`（60px）封顶：

- **红眼**：在怪物双眼处叠加红色径向光晕，越近越亮；再叠一个朝老人方向偏移的小瞳孔，做出"直勾勾盯着你"的效果。素材朝左，朝右走时红光位置随镜像翻转。
- **抖动**：绘制时给怪物加随机微抖，幅度 = `shakeMax × 强度`（最大 2.6px），越近越明显。这是**纯视觉位移**，不改 `m.x/m.y`，所以碰撞判定不变，不会出现"看着躲开了却仍被判定撞到"。
- **冻结时不抖**：被光定住的怪物保留红眼死盯你，但停止抖动（见 `update()` 里 `m.frozen` 分支）；光移开解冻后抖动恢复。

## 5. 操作与状态

- **移动鼠标**：唯一操作。光晕跟随鼠标准星，老年冒险家以 1.6px/帧平稳追光；准星处有小十字。黑暗中靠一串脚印和当前位置的常亮小圈找老人，脚下白点标示精确碰撞位置。
- **点击 Start**：开始游戏。
- **失败**：立刻显示提示，1.5 秒后可按 `R` 或点按钮重开当前关。
- **通关 Stage 1/2**：可选择"下一关"或"再来一遍"。
- **通关 Stage 3**：可选择"再来一遍"或"从头开始"（庆祝动画留待后续）。

状态机为 `START → PLAYING → LOSE / WIN`，实现在 `src/game.js`。

**碰撞约定**：静态墙和闸门是阻挡物，本体贴着它们滑行（不会死）；怪物和影障是致命物，碰到即失败。这样既满足"不能穿墙"，也避免了鼠标轻微碰壁就暴毙。

**角色身体碰撞**：角色贴图比脚点大得多，如果只按脚点判定，头顶会穿进墙里。现在额外用一个头肩代理圆参与墙体碰撞（脚圆 + 头圆都不能进墙，二分找贴墙位置）。角色尺寸随 `cell` 缩放：`h = min(36, cell/2 - 6)`，所以 Stage 3 的 40px 窄通道也不会被卡住。代理圆**不影响**拾取、受伤和出口判定（这些用脚圆）；光心则完全在鼠标准星上。

## 6. 素材说明

下列原图都保留了原文件不动，只额外生成透明 PNG 到 `assets/`：

- `monster.jpg` → `monster.png`：抠白底、暗部提亮、裁切缩放到 256×256。
- `Senior_adventurer_image/standing.jpg`、`walking_1.jpg`、`walking_2.jpg` → 三张 192×256 的冒险家帧。`standing` 用于停步，两张行走帧在移动时匀速交替（不再区分支撑/迈步）。两张图本身是同一条腿在前，所以这里只求平稳行走的观感，不模拟严格左右换脚。
- `Treasure_fragments_image/Treasure fragments.jpg` → `fragment.png`：256×256 淡蓝晶体，替换了原来的白色菱形。拾取时会炸开白 + 淡蓝粒子。

素材默认朝左，因此：怪物和冒险家向左走用原图，向右走用 `ctx.scale(-1, 1)` 水平镜像；怪物冻结时加白色描边圈，刹车时身后画两道红色划痕。

## 7. 调试钩子

浏览器控制台里可用：

```js
__lantern.getState()      // 'START' | 'PLAYING' | 'LOSE' | 'WIN'
__lantern.getLevel()      // 当前关卡配置
__lantern.getWorld()      // 玩家 / 怪物 / 碎片 / 机关的实时对象
__lantern.getLevelIndex()
__lantern.getLight()      // 当前光心（鼠标准星）坐标
__lantern.loadLevel(2)    // 直接跳到第三关（0/1/2）
__lantern.setTarget(300, 400) // 直接把光心设到画布坐标
__lantern.hasLineOfSight(a, b) // 两点之间是否被墙/闸门/影障挡住
__lantern.getOccluders()      // 当前帧参与遮挡的线段
__lantern.getTrail()          // 当前脚印数组 [{x, y, t}]
__lantern.getClock()          // 本关累计毫秒（脚印淡出用）
__lantern.getLang()           // 当前界面语言 'zh' | 'en'
__lantern.setLang('en')       // 切换界面语言
```

## 8. 中英文切换

- 词条全部集中在 `src/i18n.js` 顶部的 `DICT`：两个字典键名一一对应，带参数的函数式词条（如 `fragments(n)`、`winDetail(a,b)`）负责拼接数字与时间。
- 静态文字（标题、标题栏、开场面板、页脚、Canvas 的无障碍标签）在 `index.html` 上用 `data-i18n` / `data-i18n-html` / `data-i18n-aria` 标记，切换时由 `I18n.apply()` 统一更新。
- 动态文字（HUD、失败/通关面板、倒计时按钮）由 `game.js` 通过 `L(key, ...)` 取词；`I18n.onChange()` 回调会在切换时重绘这些面板，因此**在游戏中途切换也不会丢失进度**，失败冷却状态照旧。
- 语言偏好写入 `localStorage` 的 `lantern-lang`；`file://` 下不可用时静默降级为本次会话有效，不影响游戏。
- 关卡名保持 `Stage 1 / 2 / 3` 不翻译，中英文一致，避免关卡数据被语言层污染。
- 切换按钮固定在标题栏右端（`style.css` 的 `.lang-switch`），位于 600×600 画布之外，不存在遮挡画面或误触游戏的情况。
